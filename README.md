# 🎮 XZ — Интернет-магазин компьютерных игр

Веб-приложение интернет-магазина цифровых копий игр с элементами геймификации. Проект разработан в рамках курсовой работы с использованием связки **Laravel + Vue.js**.

🔗 **Демо-версия:** [razxcer.beget.tech](http://razxcer.beget.tech)

---

## ✨ Основной функционал

* **Каталог и карточки игр:** удобный просмотр ассортимента, фильтрация и детальная информация о проектах.
* **Избранное и корзина:** добавление игр в список желаемого, управление составом заказа и оформление «покупки».
* **Мини-игра «Испытай себя!»:** интерактивная механика прямо в разделе корзины, позволяющая пользователю пройти испытание и получить персональную скидку на заказ.
* **Личный кабинет и авторизация:** регистрация пользователей, хранение истории действий и управление профилем.

---

## 🛠 Стек технологий

* **Backend:** PHP 8+, Laravel
* **Frontend:** Vue.js, JavaScript (ES6+), HTML5, CSS3
* **База данных:** MySQL
* **Сборка и инструменты:** Vite / NPM, Composer, Git
